# Component Registry

Every visual component must eventually record:

- ID
- name
- owner feature
- responsibility
- states
- accessibility behavior
- RTL behavior
- tests
- status

Initial families:

- buttons
- icon buttons
- text inputs
- search inputs
- switches
- sliders
- selectors
- menus
- dialogs
- bottom sheets
- toasts
- banners
- cards
- list rows
- avatars
- badges
- loaders
- progress indicators
- empty states
- error states
- message bubbles
- composer controls
- attachment previews
- voice indicators
