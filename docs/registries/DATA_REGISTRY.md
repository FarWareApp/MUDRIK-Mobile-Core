# Data Registry

Data classes:

## Persistent structured
Examples:
- conversations
- messages
- projects
- user preferences

## Secure
Examples:
- session secrets
- sensitive credentials

## User files
Examples:
- attachments
- exports
- project files

## Cache
Disposable and rebuildable.

## Temporary
Automatically cleanable.

Every dataset must define:
- owner
- storage location
- retention
- deletion
- migration
- backup eligibility
- sensitivity
